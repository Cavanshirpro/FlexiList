# 🛡️ Security Policy

## 📌 Supported Versions

The following table indicates which versions of FlexiList currently receive security updates:

| Version | Supported |
| ------- | --------- |
| 1.0.x   | ✅ Yes    |
| < 1.0   | ❌ No     |

---

## 🔍 Reporting Vulnerabilities

If you discover a security vulnerability within FlexiList, please **do not** report it as a public issue.

Instead, please follow these steps:

1. Send a security report directly to the project maintainer via email.
2. Include full details of the vulnerability, steps to reproduce, and potential impact.
3. Our team will investigate and respond within 48 hours.
4. Once resolved, a patch will be released and your contribution will be acknowledged.

Thank you for helping keep FlexiList secure!
