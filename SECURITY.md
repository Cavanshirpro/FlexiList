# 🛡️ Güvenlik Politikası (Security Policy)

## 📌 Desteklenen Sürümler

Aşağıdaki tablo FlexiList için güvenlik güncellemeleri alan sürümleri gösterir:

| Sürüm | Destekleniyor mu? |
| ----- | ----------------- |
| 1.0.x | ✅ Evet            |
| < 1.0 | ❌ Hayır           |

---

## 🔍 Güvenlik Açığı Bildirimi

FlexiList uygulamasında veya kullanılan kütüphanelerde bir güvenlik açığı tespit ederseniz, lütfen bunu kamuya açık bir Issue olarak **yayınlamayın**.

Bunun yerine aşağıdaki adımları izleyin:

1. Güvenlik bildirimini doğrudan geliştirici e-posta adresine iletin.
2. Bildirimde güvenlik açığının detaylarını, yeniden üretme adımlarını ve etkilerini açıklayın.
3. Ekibimiz sorunu inceleyecek ve 48 saat içerisinde size dönüş yapacaktır.
4. Düzeltme yayınlandıktan sonra katkınız güvenlik duyurusunda teşekkür edilerek belirtilecektir.

Güvenliğe verdiğiniz önem için teşekkür ederiz!
