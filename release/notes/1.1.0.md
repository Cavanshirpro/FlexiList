# FlexiList 1.1.0

## Find and act faster

- Search notebook names, entry titles, notes, tags and categories across all four workspaces without a network connection. Open a result directly in its notebook or editor. Archived notebooks are included only when selected.
- Use Today to find overdue/due tasks and unfinished habits, or Starred to focus on favorite notebooks and starred entries. Filter by workspace without losing the query.
- Choose a blank notebook or preview a localized starter for weekly reviews, groceries, a daily routine, a simple workout or a reading queue. Starting content is created atomically only after saving.
- Paste one entry per line to add up to 100 entries together. Keep the entry sheet open to continue adding. Intentional duplicate lines and draft details are preserved.

## A consistent interface

- Notebook covers use their chosen colors, real completion progress and a clearer type hierarchy. Favorites, category filters and ordering remain available without crowding the list.
- Phone, tablet and large-text layouts retain the four equal workspaces. Light, Dark, System and all eight accent choices remain available.
- Consecutive entry deletions share one Undo window, so a second deletion does not discard the first recovery snapshot.
- New interface and starting content are localized in English, Turkish, Russian, German, Spanish and French.

## Compatibility and builds

- Version code 6. Existing Room data and version 1/2 backups remain compatible; no destructive database migration is needed.
- Release builds without the existing developer key are genuinely unsigned candidates. They no longer fall back to a debug key. GitHub publication still checks the existing release certificate; F-Droid continues to sign its own builds.
- Physical-device keyboard/insets, TalkBack, notification settings and live JSONBlob service verification remain separate device/service checks. Automated rendering is not a claim of full accessibility certification.
