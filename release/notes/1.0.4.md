# FlexiList 1.0.4

- Keep completed tasks completed; reset only daily workout and habit entries.
- Preserve notebook associations, item order, completion times and custom fields in backups and shared notebooks.
- Restore backups atomically and avoid losing water entries during rapid updates.
- Correct partial workout completion, workout volume and zero-rest transitions.
- Build and verify Full and F-Droid variants before publishing signed APKs with SHA-256 checksums and source metadata.

Automated JVM and Robolectric tests run on GitHub Actions. Physical-device behavior has not been qualified by these checks.
